SIP / PBX · UDP / IPv4 · G.711

Enter the password here, or leave it blank to use the environment variable. The entered password is sent to this localhost server for this start, passed through the worker's environment (not command-line arguments), and cleared from the field after a successful start. It is not saved by the app or returned in session state or diagnostics. The minimal SIP backend does not REGISTER; use a PBX that permits direct INVITEs (with optional Digest authentication). Dial creates the outgoing call; incoming SIP calling is not exposed here.

Emulator peer · local UNIX socket

Open a second GUI server on another port, not just another tab: ./courier gui --port 8766. Choose the same socket, one Listen and one Connect; start both within 30 seconds. Socket role is not call direction. Dial on the caller and Answer on the other end; PCM-only mode has no generated dial tone, so ATX0 may be needed before dialing. Remove a stale socket only after both workers are stopped.

Unchecking PCM only uses the existing modeled call/carrier helpers. A resulting CONNECT is not proof of DSP-only training. Even in PCM-only mode, firmware support is not fully qualified; main211 has known call-training limitations.

Experimental physical FXO bridge · macOS only

Not a general USB/serial modem driver. Requires macOS audio permission, libusb, the Apple A1082, and the built hardware-only helper (tools/build_apple_line.py). An FXO must not be connected directly to another unpowered modem. Use the qualified firmware/board settings; main211 call training is not qualified.

Stop normally requests worker cleanup and hook release. Verify the helper's on-hook readback in Worker diagnostics; if it fails or the process crashes, check the line and unplug the modem if necessary. No software can guarantee hook release after a host crash.

Analog board settings (firmware-dependent)

Do not apply a fixture blindly. The documented captured 4.03 physical-line setup uses board 7, idsdl403, and the default timer. Select its directory with --directory to use the captured ROM. DTE format defaults to 8N1 at the byte attention adapter; it changes the modem's active serial format, not just its display. Preserve stored framing leaves that setting untouched. These options do not load or persist your hardware EEPROM.

Call controls · analog only

Wait for firmware startup before dialing. In data mode, use Escape, wait for the firmware's OK, then Hang up. Escape pauses terminal input on both sides of +++ (no Enter); increase its guard if you changed S12. ATH is a command, not an out-of-band disconnect.

Serial terminal

Commands are sent with a carriage return. Output and carrier lamps are from the emulator; “Running” is not a connected call. Boot may take a moment. 8-bit text is the default and preserves all eight bits. Optional 7-bit text strips parity for display and transcript export only; it does not fix UART framing. The original console bytes are retained in the session, and transmitted input is unchanged. This is a command console, not a binary terminal. No connection mode guarantees successful modem negotiation.
