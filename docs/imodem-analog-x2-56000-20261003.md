# Analog x2 56000 controls, 2026-10-03

The rate of 56000 bps is not verified. The highest connection that has correct messages in the two directions,
no guest NO CARRIER and no CPU/DSP error is still
[53333 bps](../artifacts/imodem-analog-x2-53333-production-20261003/verification.json).
These controls do not show that 53333 is a fundamental ceiling.

All five runs use the same NI1 profile, 20 ms exchanges, 600 million I-modem
instructions and 450 million analog instructions. The working configuration
starts with S54=0/S58=48 on the two ends and analog &U26/&N39.
We do not inject a carrier, a rate, a training decision or a payload.

| Change from the working configuration | Analog result | Both messages intact | Guest NO CARRIER | Evidence |
|---|---|---|---|---|
| Request 56000 only, with &U38/&N38 | No CONNECT | No | Both ends | [Verification](../artifacts/imodem-analog-x2-56000-request-20261003/verification.json) |
| Kaiser beta 5, 4096 interpolation phases | No CONNECT | No | Both ends | [Verification](../artifacts/imodem-analog-x2-56000-beta5-20261003/verification.json) |
| Downstream level +1.5 dB | 53333/x2/LAPM/V42BIS | Yes | No end | [Verification](../artifacts/imodem-analog-x2-56000-rx-plus1p5-20261003/verification.json) |
| 3072 interpolation phases, original beta 8 | 53333/x2/LAPM/V42BIS | Yes | Analog end | [Verification](../artifacts/imodem-analog-x2-56000-phases3072-20261003/verification.json) |
| Ordinary analog S58=32, server S58=48 | No CONNECT | No | Both ends | [Verification](../artifacts/imodem-analog-x2-56000-serverpower-20261003/verification.json) |

For the 56000 request, the I-modem terminal reports 33333/x2 before it loses the carrier.
The analog terminal does not report CONNECT. The minimum request of the host is
not an absolute enforcement mechanism, because the original firmware also keeps
its lowest fallback rate in the mask.

The beta-5 filter makes the upper passband flatter, but it decreases the stopband rejection.
Its tone SNR is 57.77 dB at 3.8 kHz and 50.58 dB at 3.9 kHz. These values include
the amplitude error and the phase error. This filter does not establish the carrier.

With 3072 phases, the fractions of the 8-kHz/9.6-kHz ratio are exact,
and the FIR delay does not increase. The related tone SNR improves from
61.90 to 80.92 dB at 3.8 kHz, but the 3.9-kHz SNR stays at 26.86 dB.
But the connection rate stays at 53333, and the run reports analog
NO CARRIER. Thus, we do not use the finer phases.

The two filter experiments use separate native builds. Their patches are saved
with the artifacts. Their LIBRARY_SOURCES point to the diagnostic sources. Thus,
the loader cannot silently rebuild the production sources into the alternative
library. The production code and the verified 53333 configuration did not change.
